The fundamental theorem of Riemannian geometry often refers to the existence and uniqueness of Levi-Civita connection.
But it also refers to the result of John Nash \cite{nash-1956} that \textit{any Riemannian manifold is isometric to a smooth submanifold in a Euclidean space}.
In particular, Riemannian manifold can be defined as a submanifold of Euclidean space with induced metric tensor.

We will prove this theorem for compact manifolds and idicate its proof in general case.

In the proof we use the so-called Günther trick --- an essential simplification of the original proof that was found by Matthias Günther \cite{gunter}.
We also use several minor improvements found by Deane Yang, Terence Tao, and Ralph Howard \cite{yang,tao,howard} and cut corners everywhere we can.

\section{Induced metric}

Choose a smooth $n$-dimensional manifold $\Omega$.
Recall that a smooth field of bilinear symmetric forms, say $g$, on the tangent bundle $\T\Omega$ is called \emph{metric tensor}.
Here and further, \emph{smooth} means $C^\infty$.

Let $\bar \Omega$ be another smooth manifold and let $w\:\Omega\to\bar\Omega$ be a smooth map.
Recall that derivative of $w$ in direction of a tangent vector $\vec x\in\T_p\Omega$ is denoted by $\vec x w$ and
\[\vec x w =dw(\vec x);\] that is, the derivative of $w$ in the direction $\vec x$ is the \emph{differential} $dw$ of $w$ evaluated at $\vec x$.
Note that $\vec x w\in \T_{w(p)}\bar\Omega$.

Suppose that $\bar \Omega$ is equipped with a metric tensor $\bar g$.
Consider the metric tensor $g$ defined on $\Omega$ defined by
\[g(\vec x,\vec y)=\bar g(\vec x w,\vec yw).\]
It is called \emph{induced} metric tensor, or \emph{pullback} of $\bar g$ to $\Omega$.
This relation can be also written as $g=w^*\bar g$.
Equivalently, we can say that $w$ is an \emph{isometric map} from $(\Omega,g)$ to $\bar\Omega,\bar g)$.

A metric tensor $g$ is called \emph{Riemannian} if it is \emph{positive};
that is, if $g(\vec x,\vec x)>0$ for any tangent vector $\vec x\ne 0$.
A smooth maniflod equipped with a Riemannian metric is called \emph{Riemannian manifold}.

Note that if $g=w^*\bar g$ is Riemannian metric, then $w$ has to be regular; that is, the differential $d_pw$ has rank $n$ at any point $p\in \Omega$.
In particular, $w$ is an immesion.

The Euclidean space $\RR^q$ will be considered with standard Euclidean metric defined by the scalar product
\[g(\vec x,\vec y)\df\langle\vec x,\vec y\rangle,\]
which is a Riemannian metric.

\begin{thm}{Main theorem}\label{thm:main}
Any $n$-dimensional Riemannian manifold $(\Omega,g)$ admits an isometric embedding into a Euclidean space $\RR^q$ for some $q$ that depends only on $n$.
\end{thm}

\begin{thm}{Exercise}\label{ex:notinduced}
Construct a metric tensor $g$ on the torus $\mathbb{T}^2=\mathbb{S}^1\times \mathbb{S}^1$ such that $g(\vec x,\vec x)\ge 0$ for any tangent vector $\vec x$, but there is no smooth map $w\:\mathbb{T}^2\to \RR^{10}$ with the induced metric $g$.
\end{thm}

\section{Q-form}

Suppose $v,w\:\Omega\to\RR^q$ are two smooth maps.
Let us write $g=Q(v,w)$ if
\[
g(\vec x,\vec y)
\equiv
\tfrac12\cdot[\langle \vec xv,\vec yw\rangle+\langle \vec xw,\vec yv\rangle].
\]
The operator $Q$ is symmetric and bilinear; it takes two smooth maps $v,w\:\Omega\to\RR^q$ and spits a metric tensor $g=Q(v,w)$ on $\Omega$.

\begin{thm}{Observation}
A metric tensor $g$ is induced by a smooth map $w\:\Omega\to\RR^q$
if and only if $g=Q(w,w)$.
\end{thm}

The components of $g=Q(w,w)$ in a local chart
can be written as
\[g_{ij}=Q_{ij}(w,w)=\langle \partial_iw,\partial_jw\rangle.\]


\begin{thm}{Exercise}\label{ex:length-preserving}
Let $w$ be a smooth map from a smooth Riemannian manifold $(\Omega,g)$ to the Euclidean space $\RR^q$.
Show that $w$ is isometric if and only if it is \index{length-preserving}\emph{length-preserving};
that is, if
\[\length\gamma=\length(w\circ\gamma)\]
for any curve $\gamma$ in $\Omega$.
\end{thm}

Let $\Omega$ be a smooth manifold.
Given two smooth maps $v_1\:\Omega\to\RR^{q_1}$ and $v_2\:\Omega\to\RR^{q_2}$, denote by $w=v_1\oplus v_2$ the map
\[w\:\Omega\to\RR^{q_1+q_2}=\RR^{q_1}\oplus\RR^{q_2}\]
defined by
$w\:p\mapsto (v_1(p),v_2(p))$.

\begin{thm}{Exercise}\label{ex:oplus}
Show that
\[Q(v_1\oplus v_2,v_1\oplus v_2)=Q(v_1,v_1)+Q(v_2,v_2)\]
for any two smooth maps $v_1\:\Omega\to \RR^{q_1}$ and $v_2\:\Omega\to \RR^{q_2}$.
\end{thm}

Recall that \emph{support} of a map is the closure of the set of its arguments with nonzero values.

\begin{thm}{Exercise}\label{ex:plus-oplus}
Let $v_1,v_2\:\Omega\to \RR^{q}$ be smooth maps defined on a smooth manifold $\Omega$.
Suppose $v_1$ and $v_2$ have disjoint supports.
Show that
\[Q(v_1+ v_2,v_1+ v_2)=Q(v_1,v_1)+Q(v_2,v_2).\]
\end{thm}

\section{Reducion to torus}

Let us denote by $\TT^n=\RR^n/(2\cdot\pi\cdot\ZZ)^n$ the $n$-dimensional torus.

The torus is a smooth manifold;
it comes with a global system of periodic coordinates which can be used to define the partial derivatives $\partial_1,\dots,\partial_n$.
A metric tensor on $\TT^n$ can be also written in these coordinates;
so we can (and will) think that a metric tensor is a smooth map $g\:\TT^n\to\RR^N$;
here and further
\[N\df\frac{n\cdot(n+1)}2.\]
These observations make it slightly easier to work with torus, then with general manifold.

In the proof of \ref{thm:main} we will reduce the general case to its partial case formulated below and then prove the restricted verson.

\begin{thm}{Restricted theorem}\label{thm:restricted}
Given a Riemannian metric $g$ on the $n$-dimensional torus $\TT^n$ there is an isometric immersion $w\:(\TT^n,g)\z\to\RR^q$ for some $q$ that depends only on $n$.
\end{thm}

\subsection*{From immersion to embedding}

\begin{thm}{Claim}\label{clm:embedding}
We can assume that $w$ in \ref{thm:restricted} is an embedding.
\end{thm}


\parit{Proof.}
Choose a Reiamannian metric $g$ on $\TT^n$.

Choose a smooth embedding $v_0\:\TT^n\to \RR^{2\cdot n+1}$;
it exists by the Whitney theorem.
(In fact there is a smooth embedding $v_0\:\TT^n\z\to \RR^{n+1}$, but it is not going to be important for us.)
Let $g_0=Q(v_0,v_0)$; in other words, $g_0$ is the metric induced by $v_0$.
Since $v_0$ is an embedding, $g_0$ must be Riemannian.

We can assume that $g>g_0$; if not, pass to rescaling $\eps\cdot v_0$ of $v_0$ for small $\eps>0$.
In other words the metric $g_1=g-g_0$ is Riemannian.

Applying the reduced theorem we get a smooth isometric immersion $v_1\:(\TT^n,g_1)\to \RR^q$.
Note that $w=v_0\oplus v_1$ is an isometric embedding $(\TT^n,g=g_0+g_1)\to \RR^{q+2\cdot n+1}$.
Indeed, $w$ is isometric by \ref{ex:oplus}, and it is an embedding since $v_0$ is.
\qeds

\subsection*{Compact case}

This part of reduction relies on the following exercise.

\begin{thm}{Exercise}\label{ex:torus-riemn}
Let $\Omega$ be a closed submanifold in the torus $\TT^n$.
Show that for any Riemannian metric on $\Omega$ is a restriction of a Riemannian metric on $\TT^n$.
\end{thm}

\parit{Reduction \ref{thm:main} to \ref{thm:restricted} in the compact case.}
Assume $\Omega$ is compact.
By the Whitney embedding theorem, there is a smooth embedding $\iota\:\Omega\z\to \RR^{2\cdot n+1}$.
Since $\Omega$ is compact, we can assume in addition that $\iota$ is short and its image lies in a small ball;
if not, then pass to the rescaling $\eps\cdot\iota$ of $\iota$ for small $\eps>0$.
Composing $\iota$ with the covering map $\RR^n\to \TT^{2\cdot n+1}$, we get an embedding
$\Omega\hookrightarrow\TT^{2\cdot n+1}$.

In particular, we can assume that $\Omega$ is a compact submanifold of a torus.
By \ref{ex:torus-riemn}, any Riemannian metric $g$ on $\Omega$ is the restriction of a Riemannian metric, say $\bar g$, on $\TT^{2\cdot n+1}$.

Choose an isometric smooth embedding $w\: (\TT^{2\cdot n+1},\bar g)\to\RR^q$ provided by \ref{clm:embedding}.
Observe that the composition $f\circ\iota\:(\Omega,g)\to \RR^q$ is isometric.
\qeds

\subsection*{Noncompact case}

For noncompact manifold $\Omega$, reduction \ref{thm:main} to \ref{thm:restricted} is more technical.
It is based on the following two exercises.

\begin{thm}{Exercise}\label{ex:short-embedding}
Let $\Omega$ be a connected noncompact manifold.
Show that it admits a smooth proper bounded embedding in $\RR^q\setminus\{0\}$.
Moreover, given a Riemannian metric $g$ on $\Omega$, we can assume that the induced metric of this embedding is smaller than $g$.
\end{thm}

Let $\Omega$ be an $n$-dimensional manifold.
A smooth map $r\:\Omega\to \SSS^n$ will be called \emph{chart-like} if there is an open disc $D\subset \Omega$ such that
the restriction $r|_D$ is a diffeomorhism $D\to \SSS^n\setminus\{p\}$ for some point $p\in \SSS^n$ and
$r(x)=p$ for any $x\in \Omega\setminus D$.
The disc $D$ is called the domain of the chart-like map $r$.

The following exercise is a combintaion of partition of unity and dimension theory.

\begin{thm}{Exercise}\label{ex:sum}
Let $(\Omega,g)$ be an $n$-dimensional noncomapct connected Riemannian manifold then there is a counable collection of chart-like maps $r_i\:\Omega\to \SSS^n$ with domains $D_i$ and a sequence of Riemannian metrics $h_i$ on $\SSS^n$ such that
\[g=\sum_j r_j^*h_j\]
and the sequence $D_i$ can be divided into $n+1$ subcollecions such that $\bar D_i\cap \bar D_j=\emptyset$ if $D_i$ and $D_j$ belong to one subcollection; here $\bar D_i$ denotes the closure of $D_i$.
\end{thm}


\parit{Reduction of the main theorem to its compact case.}
Let $w\:\Omega\to\RR^q$ be an embedding provided by \ref{ex:short-embedding} for metric $\tfrac12\cdot g$.
Let $g_0$ be the metric induced by $w$;
note that $g_1=g-g_0$ is a Riemannian metric.

Let us apply \ref{ex:sum} to $(\Omega,g_1)$;
denote by $r_i$, $h_i$, and $D_i$ the obtained maps, metrics and domains.
Since $\SSS^n$ is compact, there is an isometric embedding $w_i\:(\SSS^n,h_i)\z\to \RR^q$;
we can assume that $w_i\circ r_i$ maps all points in $\Omega\setminus D_i$ to zero;
in particular, each $w_i$ has compact support.

Let $S_1,\dots,S_{n+1}$ be the subdivision of natural numbers provided by \ref{ex:sum};
that is $j,k\in S_i$ for some $i$ if and only if $D_j$ and $D_k$ belong to one of subcollections of domains.
Set
\[s_i=\sum_{j\in S_i} w_j\circ r_j
\quad\text{and}\quad
s=s_1\oplus\dots\oplus s_{n+1}.
\]
By \ref{ex:plus-oplus} and \ref{ex:oplus},
\begin{align*}
Q(w\oplus s,w\oplus s)&=Q(w,w)+\sum_i Q(s_i,s_i)=
\\
&=g_0+\sum_j Q(w_j\circ r_j,w_j\circ r_j)=
\\
&=g_0+\sum_j r^*_jh_j
\\
&=g_0+g_1=g.
\end{align*}
Since $w$ is an emebdding, so is $w\oplus s$, hence the result.
\qeds

\section{Free maps}

As before, $\Omega$ is a smooth $n$-dimensional manifold.

Recall that a $C^1$-map $f\:\Omega \to \RR^q$ is called \emph{regular} if its differential $df$ has rank $n$ at each point.
In other words, for any point $p\in \Omega$ and some (and therefore any) local coordinates at $p$ all $n$ first-order partial derivatives $\partial_1f,\dots,\partial_nf$ are linearly independent.

A $C^2$-map $f\:\Omega \to \RR^q$ is called \emph{free} (or \emph{two-regular}) if an analogous property holds for first \textit{and second} partial derivatives;
that is, for any point $p\in \Omega$ and some (and therefore any) local coordinates at $p$ all $n+\tfrac{n\cdot(n+1)}{2}$ partial derivatives 
$\partial_if$,
$\partial_{ij}f$ for $i\le j$
are linearly independent.

\begin{thm}{Exercise}\label{ex:free-dim}
Show that there is no free map $\mathbb{S}^2
\to \RR^4$.
\end{thm}

\begin{thm}{Exercise}\label{ex:free-sum}
Let $f_1\:\Omega\to \RR^{q_1}$ and $f_2\:\Omega\to \RR^{q_2}$ be smooth maps defined on a smooth manifold $\Omega$.
Suppose $f_1$ is free; show that so is $f_1\oplus f_2$.
\end{thm}

Let $f$ be a smooth function on a manifold $\Omega$.
Denote by $E_f$ the smooth map $\Omega\to \RR^2$, defined by 
\[E_f(x)=(\cos [f(x)],\sin [f(x)]).\]
In other words, $E_f$ is the composition of two maps
\[\Omega\xrightarrow{f}\RR\xrightarrow{\ell}\SSS^1\subset\RR^2,\]
where $\ell\:\RR\to\SSS^1$ is the natural covering maps $y\mapsto (\cos y,\sin y)$.


\begin{thm}{Exercise}\label{ex:free-twists}
Consider the $(x,y)$-plane $\RR^2$.
Show that the map 
\[E_x\oplus E_y\oplus E_{x+y}\:\RR^2\to \RR^6=\RR^2\oplus\RR^2\oplus\RR^2\]
is free.

Generalize the statement to maps $\RR^n\to \RR^{n\cdot(n+1)}$. 
\end{thm}

\begin{thm}{Exercise}\label{ex:free-composition}
Let $f\:\Omega \to \RR^s$ be a regular smooth map and $F\:\RR^s\z\to \RR^q$ is free.
Show that the composition $F\circ f\:\Omega \to \RR^q$ is free.

Apply the Whitney embedding theorem and \ref{ex:free-twists} to conclude that any smooth manifold admits a free embedding into a Euclidean space.
\end{thm}

\section{Digression into Fourier series}

Recall that $\TT^n=\RR^n/2\cdot\pi\cdot \ZZ^n$ denotes the $n$-dimensional torus;
it comes with a standard system of periodic coordinates which can be used to define the partial derivatives $\partial_1,\dots,\partial_n$.

For an $L^2$-function $u\:\TT^n\to\RR^q$ the coefficients in its Fourier series
\[\sum_{m\in \ZZ^m} a_m\cdot \exp(i\cdot \langle m,x\rangle)\]
form an $n$-dimesional sequence from $\CC^q$.
The vector $a_m$ for $m\in \ZZ^n$ will be denoted by $\mathcal{F}_m(u)$; it is defined as the avarage value
\[
\mathcal{F}_m(u) \df \xint_{x\in\mathbb{T}^n} u(x) \cdot\exp(-i \cdot \langle m,x\rangle),
\]
here $x$ stands for a point in $\TT^n$ as well as a corresponding point in $\RR^n$ defined modulo $2\cdot\pi\cdot\ZZ^n$.

By Parseval's formula, we have
\[\|u\|_{L^2(\TT^n,\RR^q)} = \sqrt{\sum_{m \in \mathbb{Z}^n} |\mathcal{F}_m(u)|^2}.\]
Let us define $k^{\text{th}}$ Sobolev norm as
\[\|u\|_{H^k(\TT^n,\RR^q)} = \sqrt{\sum_{m \in \mathbb{Z}^n} (1+|m|^2)^k\cdot|\mathcal{F}_m(u)|^2}.\]
The subspace $L^2(\TT^n,\RR^q)$ of all functions with finite $k^{\text{th}}$ Sobolev norm will be denoted by $H^k(\TT^n,\RR^q)$.
It is straightforward to check that $u\in H^k(\TT^n,\RR^q)$ if and only if $u$ and all its partial derivatives%
\footnote{A partial derivative $w=\partial_j u$ is defined as a function $w\in L^2(\TT^n,\RR^q)$ such that equality
$\int_{\TT^n} \langle w, \phi\rangle=\int_{\TT^n} \langle u, \partial_j\phi\rangle$ holds for any smooth function $\phi\:\TT^n\to\RR^q$.}
up to order $k$ lie in $L^2(\TT^n,\RR^q)$.


\begin{thm}{Embedding theorem}
The inclusion
\[C^k(\TT^n,\RR^q) \subset H^k (\TT^n,\RR^q) \subset C^s(\TT^n,\RR^q)\]
holds for any nonnegative intergers $s$, $k$, and $n$ such that $k> s+n/2$.
In particular,
\[C^\infty(\TT^n,\RR^q)=\bigcap_sH^s (\TT^n,\RR^q).\]

\end{thm}

If $m=(m_1,\dots,m_n)\in\ZZ^n$, then
\[\mathcal{F}_m(\partial_ju)=i\cdot m_j\cdot \mathcal{F}_m(u).\]
Therefore,
\[\mathcal{F}_m(u- \Delta u)=(1+|m|^2)\cdot\mathcal{F}_m(u).\]
It follows that $1-\Delta$ defines an isometry $H^{k+2}(\TT^2)\to H^{k}(\TT^2)$;
therefore,
\[(1-\Delta)^{-1}\: H^{k}(\TT^2)\to H^{k+2}(\TT^2)\]
is an isometry.

\section{Formulations of key lemmas}

Recall that $\TT^n$ denotes the $n$-dimensional torus;
it comes with a global system of periodic coordinates which can be used to define the partial derivatives $\partial_1,\dots,\partial_n$,
and a metric tensor on $\TT^n$ can be also written in these coordinates;
so we can (and will) think that metric tensor is smooth map $g\:\TT^n\to\RR^N$;
here and further $N\df\frac{n\cdot(n+1)}2$.

Choose $0<\alpha<1$, say $\alpha=\tfrac12$.
Denote by $|x-y|_{\TT^n}$ the standard distance between points $x,y\z\in\TT^n$.
Let us recall the definition of Hölder norms of a function $u\:\TT^n\to \RR$
\begin{align*}
\|u\|_{0,\alpha}&\df\sup_{x\in \TT^n}\{\,|u(x)|\,\}+\sup_{x,y\in \TT^n}\left\{\,\frac{|u(x)-u(y)|}{|x-y|_{\TT^n}^\alpha}\,\right\},
\\
\|u\|_{k,\alpha}&\df\max_{|\mathcal{I}|\le k}\left\{\,\|\partial_{\mathcal{I}}u\|_{0,\alpha}\,\right\},
\end{align*}
where $\mathcal{I} = (i_1,\dots,i_n)$ denotes multi-index; so, $\partial_{\mathcal{I}}\df \partial_1^{i_1}\dots\partial_n^{i_n}$ and $|\mathcal{I}| \df i_1 +\dots+i_n$.
The space of functions with finite norm $\|\ \|_{k,\alpha}$ is called the $(k,\alpha)$-Hölder space; it is denoted by $C^{k,\alpha}(\TT^n,\RR)$.

\begin{thm}{Exercise}\label{ex:hoelder-norm}
Let $v\in  C^\infty(\TT^n,\RR)$.
Show that there is a constant $c$ such that
\[\|u\cdot v\|_{k,\alpha}\le c\cdot\|u\|_{k,\alpha}\]
for any $u\in  C^{k,\alpha}(\TT^n,\RR)$.
\end{thm}


Further, let us define $C^{k,\alpha}(\TT^n,\RR^q)$ as the space of functions $u\:\TT^n\z\to \RR^q$ with all coordinate functions from $C^{k,\alpha}(\TT^n,\RR)$.
Let 
\[\|u\|_{k,\alpha}\df\max_i \{\,\|u_1\|_{k,\alpha},\dots,\|u_q\|_{k,\alpha} \,\},\]
where $u_1,\dots, u_q$ are the coordinate functions of $u$.

From now on, let us fix a smooth free map $f\:\TT^n \to\RR^q$ and let
\[L(w)\df 2\cdot Q(f,w).\]

\begin{thm}{Nash's lemma}\label{lem:nash-guenter:nash}
The linear operator 
\[L\:C^\infty(\TT^n,\RR^q)\to C^\infty(\TT^n,\RR^N)\]
has a right inverse 
\[M\:C^\infty(\TT^n,\RR^N)\to C^\infty(\TT^n,\RR^q)\]
such that
\[\|Mh\|_{2,\alpha}\le a\cdot \|h\|_{2,\alpha}\]
for some constant $a$.
\end{thm}

\begin{thm}{Günther's lemma}\label{lem:nash-guenter:guenter}
There is a symmetric bilinear opearator 
\[\tilde Q\:C^\infty(\TT^n,\RR^q)\times C^\infty(\TT^n,\RR^q) \to C^\infty(\TT^n,\RR^q)\]
 such that
\begin{align*}
L\tilde Q&=Q,
\\
\|\tilde Q(w,w)\|_{2,\alpha}&\le b_2\cdot  \|w\|^2_{2,\alpha},
\\
\|\tilde Q(w,w)\|_{k,\alpha}
&\le b_2\cdot \|w\|_{2,\alpha}\cdot \|w\|_{k,\alpha}
+
b_k\cdot \|w\|_{k-1,\alpha}^2
\end{align*}
for any integer $k\ge 3$ and some fixed constants $b_2,b_3,\dots$
\end{thm}

\section{Perturbation}

Recall that $f\:\TT^n \to\RR^q$ is a fixed smooth free map and
\[L(w)\df 2\cdot Q(f,w).\]

\begin{thm}{Perturbation lemma}\label{lem:perturb}
There is  $r>0$
such that the equation 
\[L(w)+Q(w,w)=h\eqlbl{eq:L+Q=h}\]
has a smooth solution $w\:\TT^n\to\RR^q$ for any smooth metric $h$ such that $\|h\|_{2,\alpha}<r$.
Moreover, we can assume that
\[\|w\|_{2,\alpha}\le C\cdot \|h\|_{2,\alpha},\]
for some constant $C$. 
\end{thm}

Suppose that a metric tensor $g$ is induced by $f$.
Note that the equation
\[Q(f+w,f+w)=g+h\]
is equivalent to \ref{eq:L+Q=h}.
Indeed,
\begin{align*}
Q(f+w,f+w)&=Q(f,f)+2\cdot Q(f,w)+Q(w,w)
\\
&=g+L(w)+Q(w,w).
\end{align*}
Therefore the perturbation lemma implies the following.

\begin{thm}{Corollary}
Let $g$ be induced by a smooth free map $f\:\TT^n\z\to \RR^q$
and $h$ another metric tensor on $\TT^n$.
If $\|h\|_{2,\alpha}$ is sufficiently small, then $g+h$ is induced by a smooth map $\TT^n\to \RR^q$.
\end{thm}


\parit{Proof of \ref{lem:perturb}.}
Recall that $M$, $\tilde Q$, $a$, and $b_2$ are provided by \ref{lem:nash-guenter:nash} and \ref{lem:nash-guenter:guenter}.
Set $R=\tfrac1{10\cdot b_2}$ and $r=\tfrac R{10\cdot a}$. 
Assume $\|h\|_{2,\alpha}\le r$.
By \ref{lem:nash-guenter:guenter},
\[\Phi\:w\mapsto Mh-\tilde Q(w,w)\]
is a contraction map from the closed ball $\cBall[0,R]\subset {C^{2,\alpha}(\TT^n,\RR^q)}$ to itself.

Consider the sequence of maps $w_0,w_1,\dots\:\TT^n\to\RR^q$ such that $w_0=0$ and $w_{n+1}=\Phi(w_n)$ for any $n$.
Note that $w_n$ is smooth for each~$n$.
Since $\Phi$ is a contraction, $w_n$ converges in $C^{2,\alpha}(\TT^n,\RR^q)$ as $n\to\infty$;
denote its limit by $w$.
Further,
\[\|w\|_{2,\alpha}\le R
\qquad\text{and}\qquad
w= Mh-\tilde Q(w,w).\]

Since $LM=\id$ and $L\tilde Q=Q$,
applying $L$ to both sides of the last equation, we get that 
$w$ solves \ref{eq:L+Q=h}.

It remains to show that $w$ is smooth.
Suppose that 
\begin{clm}{}\label{clm:wn-bounded}
the sequence $\|w_n\|_{k,\alpha}$ is bounded for every integer $k\ge 2$.
\end{clm}
Since 
\[\|w\|_{k,\alpha}\le \liminf_{n\to\infty}\|w_n\|_{k,\alpha}\]
it follows that $w\in C^{k,\alpha}$ for any $k$;
whence $w\in C^{\infty}$.

Let us prove \ref{clm:wn-bounded} by induction on $k$.
The base case $k=2$ is proved already.

By the induction hypothesis, $\|w_n\|_{k-1,\alpha}$ is bounded.
In particular, there is a constant $c_{k}$ such that
\[\|Mh\|_{k-1,\alpha}+b_k\cdot \|w_n\|_{k-1,\alpha}^2\le c_{k}\]
for any $n$;
here $b_k$ is from \ref{lem:nash-guenter:guenter}.

By the second estimate in \ref{lem:nash-guenter:guenter}, we get
\begin{align*}
\|w_{n+1}\|_{k,\alpha}
&\le
\|Mh\|_{}
+
b_2\cdot \|w_n\|_{2,\alpha}\cdot \|w_n\|_{k,\alpha}
+
b_k\cdot \|w_n\|_{k-1,\alpha}^2\le
\\
&\le c_{k}+ b_2\cdot R\cdot \|w_n\|_{k,\alpha}\le
\\
&\le c_{k} +\tfrac1{10}\cdot\|w_n\|_{k,\alpha}.
\end{align*}
In particular, 
\[\|w_n\|_{k,\alpha}\le 2\cdot c_{k}
\qquad\Longrightarrow\qquad
\|w_{n+1}\|_{k,\alpha}\le 2\cdot c_{k}
\]
for any $n$.
Since  $w_0=0$, we get \ref{clm:wn-bounded} for $k$.
\qeds

\section{Proof of Nash's lemma}\label{sec:proof(nash)}

\parit{Proof of \ref{lem:nash-guenter:nash}.}
Recall that we have global periodic coordinates on $\TT^n$.

Choose a metric tensor $h$ on $\Omega$.
Since all $\partial_if$,
$\partial_{ij}f$
are linearly independent,
the following identities uniquely define a vector field $w$ on $\T^2\Omega$ that is spanned by $\partial_if$,
$\partial_{ij}f$ 
\begin{align*}
\langle\partial_{i}f,w\rangle&=0,
&
\langle\partial_{ij}f,w\rangle&=h_{ij}
\end{align*}
for all $i$ and $j$.

Note that
\begin{align*}
L_{ij}(w)&=2\cdot Q_{ij}(f,w)=
\\
&=\langle\partial_if,\partial_jw\rangle+\langle\partial_jf,\partial_iw\rangle=
\\
&=\partial_j\langle\partial_if,w\rangle+\partial_i\langle\partial_jf,w\rangle -2\cdot \langle\partial_{ij}f,w\rangle,
\end{align*}
it defines the required right inverse $M\:h\mapsto w$.
\qeds

Let $f\:\TT^n \to \RR^q$ be a regular smooth map and $p\in \TT^n$.
Denote by $\T_p$ the $n$-dimensional space spanned by the first-order partial derivatives $\partial_1f,\z\dots, \partial_nf$ at~$p$.
Denote by $\T_p^\perp$ the normal complement of $\T_p$ in $\RR^q$.
Let us denote by $\T\TT^n$ and $\T_p^\perp\TT^n$ the corresponding bundles over $\Omega$.
Further, denote by $\T^2_p$ the  space spanned by all first and second-order partial derivatives $\partial_if$,
$\partial_{ij}f$ at~$p$,
and let $\N_p=\T^2_p\cap\T_p^\perp$.

If $f$ is free, then $\T^2_p$ and $\N_p$ are respectively $(n\z+\tfrac{n\cdot(n+1)}{2})$
and
$\tfrac{n\cdot(n+1)}{2}$-dimensional at any point $p$.
In this case we will denote by $\T^2=\T^2\TT^n$ and $\N=\N\TT^n$ the corresponding bundles over $\TT^n$.

Suppose $w=Mh$ as in the proof above.
Since $\langle\partial_{i}f,w\rangle=0$ for every $i$, we get the following.

\begin{thm}{Observation}
The inverse $M$ in Nash's lemma (\ref{lem:nash-guenter:nash}) can be choosen so that
$Mh(p)\in \N_p$ for any $p\in \TT^n$.
\end{thm}

The following exercise provides a key to proof of Günther's lemma.

\begin{thm}{Exercise}\label{ex:Mv}
Let $f\:\TT^n\to\RR^q$ be a free map.
Given a tangent vector field $v$ on $\TT^n$ and a metric tensor $h$ on $\TT^n$, show that there is a unique
vector field $w$ in $\N\TT^n$ such that
\[2\cdot Q(f,v+w)=h.\]
In other words, given $v$, there is a right inverse $M_v\:h\mapsto v+w$ of $L$ with $w$ in $\N\TT^n$.
\end{thm}

\section{Proof of Günther's lemma}

Many symmetric bilinear opearators $\tilde Q$ satisfy $L\tilde Q=Q$.
In particular, one can take $\tilde Q=MQ$, where $M$ is provided by Nash's lemma (\ref{lem:nash-guenter:nash}).
However, this choice of $\tilde Q$ does not satisfy the required inequalities in Günther's lemma.

The actual construction of $\tilde Q$ relies on extra freedom provided by \ref{ex:Mv}.
It says that, given a tangent vector field $v$ we may choose $M$ so that
$Mh-v\in \N\TT^n$.


Recall that we have globally defined partial derivatives $\partial_1,\dots,\partial_n$ on coordinates on $\TT^n$.
In particular, we can define the Laplacian
\[\Delta u=\sum_s\partial_{ss}u.\]

The next statement easily follows from the so-called \emph{Shauder estimates} --- a result in elliptic partial differential equations.
It could be also obtained directly using Fourier analysis on torus; we omit its proof.

\begin{thm}{Proposition}\label{prop:Delta-1}
Let $k\ge 2$ be an integer and $0<\alpha\z<1$.
Then
\[(\Delta-1)\:C^{k,\alpha}(\TT^n)\to C^{k-2,\alpha}(\TT^n).\]
is a bi-Lipschitz isomorphism.
In particular, the linear operator 
\[(\Delta-1)\:u\z\mapsto \Delta u-u\]
has a Lipschitz inverse 
\[(\Delta-1)^{-1}\:C^{k-2,\alpha}(\TT^n)\to C^{k,\alpha}(\TT^n)\eqlbl{eq:Lap-1-1}\]
\end{thm}

Note that the operator $(\Delta-1)^{-1}$ smooths function --- it swallows a $C^{k-2,\alpha}$-function and spits a $C^{k,\alpha}$-function.
Also, $(\Delta-1)^{-1}$ commutes with partial derivatives; that is,
\[(\Delta-1)^{-1}\partial_i
=
\partial_i(\Delta-1)^{-1}.\]
These two properties of $(\Delta-1)^{-1}$ will be important in the following proof. 

\parit{Proof of \ref{lem:nash-guenter:guenter}.}
Recall that 
$Q_{ij}(w,w)=\langle\partial_i w,\partial_jw\rangle$.
Let us show that 
\[(1-\Delta) Q_{ij}(w,w)=A_{ij}(w)+\partial_iA_j(w)
+\partial_j A_i(w),\eqlbl{eq:Delta}\]
where each $A_{ij}$, $A_{i}$ and $A_{j}$ is a linear combination of the following quadratic forms
\[
\begin{aligned}
w&\mapsto \langle\partial_aw,\partial_bw\rangle,
&
w&\mapsto \langle\partial_{ab}w,\partial_cw\rangle,
&
w&\mapsto \langle\partial_{ab}w,\partial_{cd}w\rangle.
\end{aligned}
\eqlbl{eq:forms}
\]
for all possible indexes $a,b,c,d$.

Indeed, 
\begin{align*}
(1&-\Delta) Q_{ij}(w,w)=\langle\partial_{i} w,\partial_{j}w\rangle-
\\
&\quad-
\sum_s\left[
2\cdot \langle\partial_{is} w,\partial_{js}w\rangle
+
\langle\partial_{iss} w,\partial_jw\rangle
+
\langle\partial_{i} w,\partial_{jss}w\rangle
\right]=
\\
&=\langle\partial_{i} w,\partial_{j}w\rangle
-
2\cdot \sum_s
\langle\partial_{is} w,\partial_{js}w\rangle
+
2\cdot \langle\Delta w,\partial_{ij}w\rangle -
\\
&\quad-\partial_i\langle\Delta w,\partial_{j}w\rangle
-\partial_j\langle\Delta w,\partial_{i} w\rangle.
\end{align*}
Whence \ref{eq:Delta} follows.

Choose $A=A_{i}$ or $A=A_{ij}$ for some $i$ and $j$.
Note that 
\[
\begin{aligned}
\|A(w)\|_{0,\alpha}&\le c_2\cdot \|w\|^2_{2,\alpha},
\\
\|A(w)\|_{k-2,\alpha}&\le c_2\cdot \|w\|_{k,\alpha}\cdot \|w\|^2_{2,\alpha}+c_{k}\cdot\|w\|^2_{k-1,\alpha}.
\end{aligned}
\eqlbl{eq:A=<C}\]
for some fixed constants $c_2,c_3,\dots$
Indeed, it is sufficient to check inequalities \ref{eq:A=<C} for each form in \ref{eq:forms}, and the latter is straightforward.

Applying \ref{prop:Delta-1}, we get
\[
\begin{aligned}
\|(1-\Delta)^{-1}A(w)\|_{2,\alpha}&\le c_2\cdot \|w\|_{2,\alpha}^2,
\\
\|(1-\Delta)^{-1}A(w)\|_{k,\alpha}&\le c_2\cdot \|w\|_{k,\alpha}\cdot \|w\|_{2,\alpha} +c_{k}\cdot\|w\|_{k-1,\alpha}^2;
\end{aligned}
\eqlbl{eq:AB=<C}\]
the constants $c_2,c_3,\dots$ might be different from those above, but each of them depends only on $f$.


Further, recall that
\[
L_{ij}(w)=-2\cdot\langle\partial_{ij} f,w\rangle
+\partial_{i}\langle\partial_{j} f,w\rangle
+\partial_{j}\langle\partial_{i} f,w\rangle;
\eqlbl{eq:L-def2}
\]
see Section~\ref{sec:proof(nash)}.
Let us define
$\tilde Q$ as a linear combination of $\partial_if$ and $\partial_{ij}f$ for all $i\le j$ 
such that
\[
\begin{aligned}
-2\cdot\langle \partial_{ij}f,\tilde Q(w,w)\rangle
&=(\Delta-1)^{-1} A_{ij}(w),
\\
\langle \partial_if,\tilde Q(w,w)\rangle
&=(\Delta-1)^{-1} A_i(w)
\end{aligned}
\eqlbl{eq:tildeQ}
\]
for all $i$ and $j$.
Since $f$ is free, $\tilde Q$ is well defined.
Combining \ref{eq:L-def2}, \ref{eq:tildeQ}, and \ref{eq:Delta}, we get
\[
L\tilde Q=Q.
\] 

Let $\{e_i,e_{ij}\}_{i\le j}$ be the dual frame to $\{\partial_if,\partial_{ij}f\}_{i\le j}$ in $\T^2$.
Note that  
\[\tilde Q(w,w)=\sum_i(\Delta-1)^{-1} A_i(w)\cdot e_i-\tfrac12\cdot\sum_{i\le j}A_{ij}(w)\cdot e_{ij}.\]
Since the maps $e_i,e_{ij}\:\TT^n\to \RR^q$ are smooth, \ref{eq:AB=<C} and \ref{ex:hoelder-norm} imply the last inequality in the lemma for each integer $k\ge 3$.
\qeds


\section{Nash's twist}

In this section we prove the following statement which can be regarded as an approximate version of our restricte theorem (\ref{thm:restricted}).

\begin{thm}{Proposition}\label{prop:approx-nash}
Let $g$ be a Riemannian metric on $\TT^n$.
Then there is a metric tensor $h$ on $\TT^n$ and one-parameter family of smooth maps $w_t\:\TT^n\to \RR^q$ for $t>0$
such that 
\[Q(w_t,w_t)=g+t\cdot h\]
for any $t$.
\end{thm}

Since $Q(w_t,w_t)\to g$ as $t\to0$,
it might be tempting to pass to the limit of $w_t$ as $t\to 0$.
However, as you will see, for the sconstructed maps $w_t$ this limit is constant;
so it does not solve \ref{thm:restricted}.

The main player in the proof of the proposition is the so-called Nash's twist which are about to define.

Let $\phi$ and $f$ be smooth functions on a smooth manifold $\Omega$.
Given $r>0$, denote by $\SSS^1_r$ the circle of radius $r$ in $\RR^2$.
The \index{Nash's twist}\emph{Nash's twist} $F\:\Omega \to \RR^2$ of the triple $(r,\phi,f)$ is the following composition
\[\Omega\xrightarrow{f}\RR\xrightarrow{\ell_r}\SSS^1_r\xrightarrow{\times \phi}\RR^2,\]
where $\ell_r\:\RR\to\SSS^1_r$ is a length-preserving covering map, say 
\[\ell_r(x)=(r\cdot\cos\tfrac xr,r\cdot\sin\tfrac xr),\]
and $\times \phi$ denotes the multiplication by $\phi$; so 
\[F(x)
\df
\phi(x)\cdot (\ell_r\circ f(x)).\]

Recall that \index{$(df)^2$}$(df)^2$ denotes the metric tensor induced by 
defined by $f\:\Omega\to\RR$; equivalently,
\[(df)^2(\vec x,\vec y)\df df(\vec x)\cdot d f(\vec y)=(\vec xf)\cdot (\vec yf).\]


\begin{thm}{Claim}\label{clm:twist}
The metric tensor 
\[\phi^2\cdot (df)^2+r^2\cdot(d\phi)^2\]
is induced by Nash's twist $F$ for $(r,\phi,f)$.
\end{thm}

\parit{Computations.}
Suppose that $\vec x$ is a tangent vector on $\Omega$, then
\begin{align*}
\vec xF&=\vec x(\phi\cdot \ell_r\circ f)=
\\
&=(\vec x\phi)\cdot(\ell_r\circ f) + \phi\cdot (\ell_r'\circ f)\cdot(\vec xf).
\end{align*}

Observe that $|\ell_r|=r$, $|\ell'_r|=1$, and $\ell_r\perp \ell'_r$.
Therefore,
\[\langle \vec xF,\vec yF\rangle =r^2\cdot (\vec x\phi)\cdot (\vec y\phi)+\phi^2\cdot (\vec xf)\cdot (\vec yf).
\eqno\qed\]

Let $w\:\Omega\to \RR^q$ be a smooth map defined on a smooth manifold~$\Omega$. 
Suppose that $w_1,\dots,w_q$ are coordinate functions of $w$,
then the induced metric tensor $g$ can be written as
\[g=Q(v,w)=(dw_1)^2+\dots+(dw_q)^2.\]


In order to prove \ref{thm:restricted}, we need to find functions $w_1,\dots,w_q\:\Omega\to\RR$ that solves the above equation for a given Riemannian metric.
The following weaker form of \ref{thm:restricted} will play a key role in the proof of \ref{prop:approx-nash}.

\begin{thm}{Proposition}\label{prop:phi-f}
Let $(\Omega,g)$ be a compact $n$-dimensional Riemannian manifold.
Then  there are smooth functions 
$\phi_1,\z\dots,\phi_q,f_1,\z\dots,f_q$ on $\Omega$
such that 
\[g=(\phi_1)^2 \cdot (df_1)^2+\dots+(\phi_q)^2\cdot (df_q)^2.\eqlbl{eq:g=phidf}\]
\end{thm}


\parit{Proof.}
The metric tensor $g$ can be written in local cart $(x_1,\dots,x_n)$
as 
\[g=\sum_{i, j}g_{ij}\cdot dx_i\cdot dx_j,
\eqlbl{g=sum}\]
where $g_{ij}=g_{ji}$ are smooth functions of $(x_1,\dots,x_n)$.

Since $g$ is Riemannian, we can choose chart so that $\partial_i$ are orthonormal at a given point $p$;
in other words, $g_{ii}=1$ and
$g_{ij}=0$ at $p$ for all $i\ne j$.
Since $g_{ij}$ are smooth, given $\eps>0$, we can choose a neighborhood $U\ni p$ such that
\[g_{ii}\lessgtr 1\pm \eps
\quad\text{and}\quad
g_{ij}\lessgtr \pm \eps
\eqlbl{alpha=1}\]
for all $i\ne j$ and any point in $U$.

Observe that
\[\pm dx_i\cdot dx_j=\tfrac12\cdot (dx_i\pm dx_j)^2-\tfrac12\cdot(dx_i)^2-\tfrac12\cdot(dx_j)^2.\]
Plug this formula in \ref{g=sum} and take \ref{alpha=1} into account, assuming that $\eps$ is small.
We get that $g$ is a linear combination with positive coefficents of the metric tensors 
$(dx_i)^2$ and $(dx_i\pm dx_j)^2$ for all $i$ and $j$.
In other words, we can take the functions $x_i$ and $x_i\pm x_j$ for all $i$ and $j$ as our functions $f_1,\dots,f_q$ and find $\phi_1,\dots,\phi_q$ such that \ref{eq:g=phidf} holds in a neighborhood of $p$.

Applying a partition-of-unity argument, we get the global statement.
\qeds

In the presented proof, it is sufficient to take $2\cdot n^2$ functions in each chart;
so, if $\Omega$ is covered by $m$ charts, then one can take $q=2\cdot m\cdot n^2$ functions.
However, as it is stated in the following exercise, one may take $q$ independent of $m$.

\begin{thm}{Exercise}\label{ex:q<n}
Show that $q$ in \ref{prop:phi-f} can be bounded explicitly in terms of $n$; say, we can assume that $q=100\cdot n^{100}$.
\end{thm}

\parit{Proof of \ref{prop:approx-nash}.}
Suppose that $\phi_1,\z\dots,\phi_q,f_1,\z\dots,f_q$ are provided by \ref{prop:phi-f}.
Let $r=\sqrt{t}$;
denote by $F_i$ the Nash's twist for the triple $(r,\phi_i,f_i)$.
By \ref{clm:twist},
\[w_t=F_1\oplus\dots\oplus F_q\]
is the needed map with 
$h=(d\phi_1)^2+\dots+(d\phi_q)^2$.
\qedsf

\section{Proof assembling}

\parit{Proof of \ref{thm:restricted}.}
Choose a free map $f_1\:\TT^n\to \RR^q$;
it exists by \ref{ex:free-twists}.
Suppose $g_1$ is the metric tensor induced by $f_1$.
We can assume that $g_1<g$; that is, $g_1(\vec x,\vec x)<g(\vec x,\vec x)$ for any tangent vector $\vec x\ne 0$.
In particular, $g_2=g-g_1$ is a Riemannian metric.

Applying \ref{ex:nash}, we get a metric tensor $h$ on $\TT^n$ such that for any $t>0$ there is a smooth map $f_2\:\TT^n\to \RR^{q_2}$ that induces $g_2+t\cdot h$.

By the perturbation lemma, for any small $t>0$ there is a smooth map $w\:\TT^n\to \RR^{q_1}$ such that 
\[Q(f_1+w,f_1+w)=g_1-t\cdot h.\]

Finally by \ref{ex:oplus}, the metric tensor 
\[g=g_1-t\cdot h+g_2+t\cdot h\]
is induced by the map $(f_1+w)\oplus f_2$.
\qeds

\section{A pseudoeuclidean degression}

Let us denote by $\RR^r\ominus\RR^s$ the pseudoeuclidean space with signature $(r,s)$;
that is, the space $\RR^{r+s}$ with scalar product defined by
\[\langle x,y\rangle=x_1\cdot y_1+\dots+x_s\cdot y_s-x_{s+1}\cdot y_{s+1}-\dots-x_{s+r}\cdot y_{s+r},\]
where $x_i$ and $y_i$ denote the coordinates of vectors $x$ and $y$ in $\RR^{r+s}$.

\begin{thm}{Problem}
Show that any metric $g$ on a smooth manifold $\Omega$ is induced by a smooth embedding $\Omega\to \RR^r\ominus\RR^s$ for large $r$ and $s$.
\end{thm}


\parit{Solution based on Nash's theorem.}
Note that $g=g_1-g_2$ for two Riemannian metrics $g_1$ and $g_2$ on $\Omega$.
By Nash's theorem, we can find two smooth embeddings $f_1$ and $f_2$ of $\Omega$ to $\RR^q$ with induced metrics $g_1$ and $g_2$ respectively.
Then $g$ is induced by the map
\[f_1\ominus f_2\:p\mapsto(f_1(p),f_2(p))\in \RR^q\ominus\RR^q.\]
\qedsf

Now we will show that the problem can be soved using only Nash's twist.

\parit{Solution based on Nash's twist.}
Assume $g$ is Reimannian and $\phi_1,\z\dots,\phi_q,f_1,\z\dots,f_q$ are provided by \ref{prop:phi-f}.
Let $F_i$ be Nash's twist for the triple $(1,\phi_i,f_i)$, and
\begin{align*}
h&=(d\phi_1)^2+\dots+(d\phi_q)^2,
\\
\bm{F}&=F_1\oplus\dots\oplus F_q\:\Omega\to \RR^{2\cdot q},
\\
\bm{\phi}&=\phi_1\oplus \dots\oplus \phi_q\:\Omega\to \RR^{q}.
\end{align*}
According to \ref{clm:twist}, $\bm{F}$ induces $g+h$.
Note that $\bm{\phi}$ induces $h$.
Therefore $S=\bm{F}\ominus \bm{\phi}\:\Omega\to \RR^{2\cdot q}\ominus\RR^q$ induces $g$.

To solve the general case, present the metric as a difference of two Reiamannian metrics $g=g_1-g_2$.
From above, there is a smooth embeddings $S_1$ and $S_2$ into pseudoeuclidean spaces that induces $g_1$ and $g_2$ respectively.
It remains to observe that $S_1\ominus S_2$ induces $g$.
\qeds

\begin{thm}{Exercise}\label{ex:f-ominus-phi}
Let $f$ be a smooth isometric immersion of a Reimannian menifold $(\Omega ,g)$ into the sphere $\SSS^{q-1}\subset\RR^q$ and let $\phi\:\Omega \z\to \RR$ is a smooth function.
Show that $\phi^2\cdot g$ is induced by the map $\phi\cdot f\ominus \phi$.
\end{thm}

\section{Remarks}

Let us state another closely related result that shows a huge difference between $C^1$ and $C^2$ isometric embeddings.
For example, it implies that the unit sphere admits $C^1$ length-preserving embedding into an arbitrarily small ball in Euclidean 3-space.
There is no such $C^2$-embedding since Gauss curvature of the unit sphere is 1, but at an extremal point it must be at least $\tfrac1{r^2}$, where $r$ is the radius of the ball.

\begin{thm}{Nash--Kuiper theorem}
Let $(\Omega ,g)$ be a $n$-dimensional Riemannian manifold and $f\:(\Omega ,g)\to \RR^q$ be a short smooth regular map.
Suppose that $q\ge n+1$.
Then for any $\eps>0$ there is an $C^1$-smooth length-preserving maps $f_\eps\:(\Omega ,g)\to \RR^q$ that is $\eps$ close to $f$;
that is, $|f_\eps(x)-f(x)|<\eps$ for any $x\in \Omega$.

Moreover if $f$ is an embedding then we can assume that so is $f_\eps$.

\end{thm}

It was originally proved by John Nash \cite{nash-1954} with the condition $q\z\ge n+2$ and improved to $q\ge n+1$ by Nicolaas Kuiper \cite{kuiper-1955}.
The original proof uses Nash's twist in a different way.
Both papers are reader-friendly.
One may also start with lectures by Allan Yashinski and the author \cite{petrunin-yashinski} where related results were obtained using an alternative approach.

The discussed result formed a part of foundations of the so-called \emph{homotopy principle}, or \emph{h-principlee}; an excellent introduction is given in the book by Yakov Eliashberg and Nikolai Mishachev \cite{eliashberg-mishachev}.

Many related questions are open.
For example, it is unknown if \textit{a neighborhood of any point in 2-dimensional Riemannian manifold admits a smooth length-preserving embedding into $\RR^3$}.


The compactness condition can be removed; we will give a hint how to do it.
Moreover the value $q$ can be estimated in terms  $n=\dim\Omega$.
We will give a hint how to get a ruf bound, say $q=100\cdot n^3$.
The best known estimate so far is
\[q=\max\{\,\tfrac{n\cdot(n+5)}{2},\tfrac{n\cdot(n+3)}{2}+5\,\}.\]
